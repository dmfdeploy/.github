# .github

This repository holds the organization profile for [dmfdeploy](https://github.com/dmfdeploy) and its default community health files.

- [`profile/README.md`](profile/README.md) is the organization profile shown on the [dmfdeploy](https://github.com/dmfdeploy) page.
- The default community files apply to every repository in the organization that does not have its own copy: [`SECURITY.md`](SECURITY.md), [`SUPPORT.md`](SUPPORT.md), [`GOVERNANCE.md`](GOVERNANCE.md), [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) and [`CODEOWNERS`](CODEOWNERS).

The project itself lives in the [dmfdeploy umbrella repository](https://github.com/dmfdeploy/dmfdeploy), which holds the backlog, the decision record and the documentation.

## For contributors

`AGENTS.md`, `CLAUDE.md` and `QWEN.md` hold instructions for AI coding agents that help maintain this repository. Human contributors can skip them.
